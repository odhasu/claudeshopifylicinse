title: Urgency Elements Setup
section: Feature Guides
---

Urgency elements can increase conversion by encouraging faster purchase decisions.

Enable and configure these in **Vexel Settings → Urgency**:

- Countdown timer
- Low-stock indicator
- Live visitor badge

Use urgency honestly and tie values to real inventory/sale windows.
