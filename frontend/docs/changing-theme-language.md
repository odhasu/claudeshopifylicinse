---
title: Changing Theme Language
section: Theme Customization
---

You can translate theme text from Shopify without editing code.

Go to **Online Store → Themes → Actions → Edit default theme content**.

Search any label, button text, or message and replace it with your preferred language.

For full multilingual storefronts, connect a Shopify translation app like Weglot or Langify.
